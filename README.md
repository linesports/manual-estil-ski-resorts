# Manual d’estil — Ski resorts

Visor interactiu de referències d’Instagram sobre comunicació i publicitat de marques en estacions d’esquí.

La pàgina pública es publica amb GitHub Pages des de `index.html`.

Els pòsters i les imatges del visor es serveixen des de `media/`. Els vídeos de les Stories també s’hi serveixen com a MP4 optimitzats per a la reproducció al visor; els Reels i vídeos del feed enllacen la publicació original d’Instagram. Aquest projecte es manté i es publica des de GitHub Pages.
