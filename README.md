# Manual d’estil — Ski resorts

Visor interactiu de referències d’Instagram sobre comunicació i publicitat de marques en estacions d’esquí.

La pàgina pública es publica amb GitHub Pages des de `index.html`.

Els pòsters, les imatges i els vídeos del visor es serveixen des de `media/`. Les Stories, els Reels i els vídeos del feed es reprodueixen com a MP4 optimitzats per al web; cada peça manté l’enllaç a la publicació original d’Instagram. Aquest projecte es manté i es publica des de GitHub Pages.
