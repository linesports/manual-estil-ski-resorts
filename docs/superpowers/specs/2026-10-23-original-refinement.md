# OLAF — refinament de l’original

Aprovació: l’usuari ha escollit executar fotografia i enquadrament, fonts adequades a pantalla, selector d’estació explícit, menys distància a les peces i mapa integrat sense requadre.

Preservar Inter, neu/blau pissarra, fotografia amb degradats, HTML/CSS/JS estàtics, URL i funcions de consulta, corpus i desades. Sense nova portada, canvi d’arquitectura, targetes afegides ni publicació.

La capçalera ha de llegir-se com un sol conjunt: identitat, territori, fotografia i geografia. El mapa serà una capa cartogràfica sense marc, vores ni ombra; ubicació i enllaç tenen lectura pròpia. El mapa complet es podrà obrir de manera explícita, amb teclat i recuperació si falla. Les atribucions es conserven llegibles.

Fotografia: fonts oficials de més resolució abans de SwinIR selectiu; variants web amb dimensions, mides i srcset. Portades de col·leccions seleccionades per mostrar contingut pertinent i retall adequat; evidències originals intactes.

Abast corregit per l’usuari: NOMÉS ESCRIPTORI. No dissenyar, generar variants ni validar una versió mòbil. Preservar les regles estretes originals sense iterar-les. Verificar escriptori a1280,1440 i1920px, teclat, canvi d’estació, historial, filtres, fonts i desades.
