# OLAF

Visor públic de referències de presència de marques a les estacions d’esquí, per consultar, comparar i guardar evidències. Interfície en català; publicacions i textos originals preservats. Corpus, fonts, anàlisis, coautories, deduplicació i desades locals tenen autoritat pròpia i no canvien amb la direcció visual.

Estacions, Marques, Categories i Desades són vistes existents. L’estació i les activacions agrupen peces; cada peça manté accés a autoria, font, text i anàlisi. La web és HTML/CSS/JavaScript estàtic, amb GitHub Pages com a destí posterior a revisió. El treball actual manté l’abast d’escriptori.
